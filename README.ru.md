# Судно-Проект — расчёт судов и чертежи (Windows)

Windows 10/11 x64, .NET 8 WPF, самодостаточная сборка (.NET ставить не нужно).

## Расчёты
- **Корпус**: параметрический (L, B, T, D, Cb, Cm, смещение полноты; Cb подбирается точно, V-образные оконечности), корпус Уигли и понтон (эталоны), таблица плазовых ординат (CSV, импорт/экспорт). Пример: `Примеры\wigley_60m_ordinaty.csv`.
- **Гидростатика** на серии осадок: V, Δ, LCB, KB, Awp, LCF, BMt, BMl, KMt, TPC, MCT, Cb, Cm, Cp, Cw, смоченная поверхность; таблица, графики, экспорт CSV.
- **Кривые Бонжана** и строевая по шпангоутам.
- **Нагрузка и остойчивость**: таблица статей (масса, LCG, VCG, TCG, момент свободной поверхности) → осадка, дифферент, осадки носом/кормой, крен, GM₀ и исправленная GM; диаграмма GZ по точному расчёту накрененного корпуса (KN), пантокарены, восстанавливающий момент, проверка общих критериев ИМО IS Code 2008 (площади 0–30°, 0–40°, 30–40°, GZ≥0,2 м при ≥30°, угол максимума ≥25°, GM≥0,15 м).
- **Сопротивление и мощность**: Holtrop–Mennen (трение ITTC-57, форм-фактор, волновое, бульб, транец, выступающие части, корреляционная надбавка), PE/PD/PB, морской запас.
- **Надводный борт**: упрощённая оценка по КГМ-66, тип B (ориентировочно).

## Чертежи
2D-редактор: отрезок, полилиния, прямоугольник, окружность, дуга по 3 точкам, выровненный размер, текст; слои (цвет, видимость), привязка к точкам и сетке, орто (Shift), перемещение, удаление, отмена/возврат, масштаб колесом, сдвиг средней/правой кнопкой.
«Теоретический чертёж из корпуса» строит бок с батоксами, полушироту с ватерлиниями и корпус (шпангоуты) с размерами.
Экспорт **DXF** (netDxf, открывается в AutoCAD/КОМПАС/nanoCAD/LibreCAD), **PNG**, **PDF** (векторный; кириллица в PDF транслитерируется). Открытие DXF.

## ИИ-помощник
GigaChat (официальный API), DeepSeek, YandexGPT, любой OpenAI-совместимый API (OpenAI, OpenRouter, Ollama…). Ключи — во вкладке «Настройки ИИ». Кнопки «Объясни результаты», «Проверь остойчивость», «Предложи изменения», «Оцени сопротивление»; результаты текущих расчётов передаются как контекст; режим «спросить все модели и сравнить».

## Проверка
14 модульных тестов: понтон — точное совпадение гидростатики и GZ с формулой «прямостенного» судна; корпус Уигли — V, Cb=4/9, Cm=Cw=2/3, KB=5T/8, BMt, BMl аналитически (погрешность <0,1 %); пример Holtrop–Mennen (S=7381,45 м², RF=869,6 кН); посадка/крен; CSV; DXF/PDF.

Расчёты учебные/предварительные. Для проектной документации используйте сертифицированное ПО и Правила РС.
